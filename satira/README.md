# OBSCURA/07 · Archivio Satirico
## Manifesto Imperiale della Supremazia del Topo

Pagina web autonoma, con un ministero **immaginario** e un decreto satirico che parodia i documenti istituzionali. Nessun uso di loghi o sigilli reali.

- \`index.html\`: testo completo in HTML semantico e selezionabile.
- \`manifesto.css\`: impaginazione responsive e stampa A4 via \`@media print\`.
- Nessun JavaScript, framework, font esterno, cookie, CDN o token.
- Il testo comprende i dieci articoli principali e due disposizioni finali.
- Anteprima locale: apri \`index.html\` in un browser.
- Percorso nel sito OBSCURA/07: \`/satira/\`.

**Non è un atto ufficiale:** ministero, stemma e timbri sono creazioni satiriche.

Questa cartella può essere estratta e utilizzata come radice di un repository GitHub dedicato alla satira, senza dover modificare HTML o CSS (salvo i link di ritorno relativi a OBSCURA).
